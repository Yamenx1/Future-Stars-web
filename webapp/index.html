How the score works

One formula per unit. Example bars: Lamine Yamal (forward), score 21.82.

Goals (G/90 x 3)+0.87
Assists (A/90 x 2)+0.84
Dribbles (/10)+14.40
Passing (%/20)+4.20
Youth bonus (age 19)+1.50

Forwards: goals/90 x 3 + assists/90 x 2 + dribbles/10 + pass%/20 + youth bonus.
Midfielders: goals/90 x 2 + assists/90 x 2.5 + dribbles/12 + (tackles+interceptions)/40 + pass%/18 + youth bonus.
Defenders: defending (tackles+interceptions)/16 capped at 7.5 + pass%/20 + attack (goals+assists)/90 x 2 + youth bonus.
Goalkeepers: pass%/18 + (tackles+interceptions) x 0.3 + youth bonus.
Youth bonus everywhere: (22 - age) x 0.5. Dribbles dominate the forward score by design: beating a man at 18 matters.
